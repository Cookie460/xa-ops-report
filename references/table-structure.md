# 数据表结构定义

## 大盘组（AI Table 多维表）

每组三张表，在该组独立的多维表 Base 中。

### 人员名单

| 字段名 | 类型 | 说明 |
|:--|:--|:--|
| 工号 | text | 格式 WBxxxxxxxx |
| 姓名 | text | |
| 状态 | singleSelect | 在职 / 离职 / 转出 |

### 项目表

| 字段名 | 类型 | 说明 |
|:--|:--|:--|
| 项目名称 | text | 如"大盘"、"SKU" |
| 达标阈值 | number | 如 400、405 |
| 准确率阈值 | number | 如 0.95 |
| 状态 | singleSelect | 启用 / 停用 |

### 日报录入（员工每天通过表单填写）

**固定字段：**

| 字段名 | 类型 | 说明 |
|:--|:--|:--|
| 日期 | date | YYYY-MM-DD |
| 工号 | text | |
| 姓名 | text | |
| 请假 | singleSelect | 无 / 半天 / 全天 / 1小时 / 2小时 / 3小时 |
| 豁免 | singleSelect | 豁免（空=未豁免，组长标注） |
| 临时任务量 | number | 完美/超单等合计量 |
| 临时任务工时 | number | 小时，支持小数 |
| 培训工时 | number | 小时，支持小数 |

**每个正式项目对应 4 列（以"大盘"为例）：**

| 字段名 | 类型 | 说明 |
|:--|:--|:--|
| 大盘量 | number(INT) | 实际产出量 |
| 大盘工时 | number | 小时，支持小数 |
| 大盘被质检量 | number(INT) | 组长填 |
| 大盘不一致量 | number(INT) | 组长填 |

**字段 ID 映射记录在 `groups/<组名>.json` 的 `project_fields` 中。**

## WIKI 组（电子表格 Sheet）

WIKI 组使用组长维护的在线电子表格，不需要建新表。

### 绩效表（主数据源）

**最低必须包含的列（按顺序，不能缺失）：**

| 列 | 字段名 | 说明 |
|:--:|:--|:--|
| D | 日期 | Excel 序列号，系统自动转换 |
| E | 工号 | WBxxxxxxxx |
| F | 姓名 | 必须与人员表一致 |
| G | 项目类型 | 正式项目 / 临时项目 |
| H | 项目 | WIKI评测 等 |
| I | 子项目 | wiki chat-基础能力评测 等 |
| J | 任务分组 | 必须与系统配置名称一致（见名称映射） |
| K | 类型 | 生产 / 质检 / 培训-业务需求 |
| L | 标产 | 当前任务标准产量 |
| N | 作业工时 | 培训记录必填；生产/质检可为空 |
| O | 作业量 | 生产/质检必填；培训可为空 |
| Q | 绩效用作业量 | **公式列，不能删**（系统直接读此列） |
| T | 整体被抽检量 | 有质检时填 |
| U | 整体不一致量 | 有质检时填 |

### 量级登记表（请假 + 多项目工时）

矩阵格式：行=人员，列=日期（每日4列：项目/量级/非任务时长/具体内容）。

**系统读取用途：**
- 量级列填"请假" → 识别为当日请假
- 非任务时长列 → 计算等效人数（看板 CPD/吞吐）
- 具体内容列 → 解析多项目工时（如"款采集5h"），副项目工时不包含在非任务时长中

### 考勤表（请假识别，固定 sheet 名"考勤"）

A=工号，B=姓名，C 列起一天一列。

| 值 | 推送 | 看板 |
|:--|:--|:--|
| 早4 | 全勤 | 正常 |
| 事假1/年假1/丧假1/病假1 | 休 🏖️ | +1 |
| 事假上/事假下/年假上/年假下/病假上/病假下 | 半天假（阈值 750） | +0.5 |
| 含"转项"/"离职" | 不显示 | 不计入 |

### 人员表（独立文档，固定 sheet 名"人员"）

| 字段 | 说明 |
|:--|:--|
| 工号 | WBxxxxxxxx，必须准确 |
| 姓名 | 必须与绩效表姓名一致 |
| 人员状态 | 在职 / 转项 / 汰换 |
| 转项/离职日期 | Excel 序列号，该日期起不再计入 |

## 商机组（电子表格 Sheet）

商机组使用组长维护的在线电子表格，与 WIKI 组同一 Sheet MCP 但不同文档。

### 绩效表（每月新建 sheet）

文档 nodeId 固定不变，每月在同一文档内新建 sheet，命名为 `2026年X月绩效`。

**脚本自动按日期对应月份查找，fetch 脚本会读取所有月份 sheet 的历史数据，无需人工维护 sheetId。**

**列定义（按顺序）：**

| 列 | 索引 | 字段名 | 说明 |
|:--:|:--:|:--|:--|
| A | 0 | 日期 | Excel 序列号 |
| C | 2 | 姓名 | |
| G | 6 | 任务分组 | 项目名称 |
| H | 7 | 类型 | 生产 / 质检 / 培训-业务需求 |
| I | 8 | 标产 | 原始标产阈值 |
| J | 9 | 标产2 | 调整后标产（有则用此替代 I） |
| K | 10 | 爬坡目标 | 新人爬坡阶段目标值（有则优先） |
| L | 11 | 作业量 | |
| N | 13 | 绩效用作业量 | 公式列 `IF(K=0, IF(J=0, 1500*L/I, 1500*L/J), 1500*K/8)` |
| P | 15 | 准确率阈值 | 如 0.95 |
| Q | 16 | 被质检量 | |
| R | 17 | 不一致量 | |
| S | 18 | 应审量 | 用于看板等效人数计算（= 项目工时） |

**与 WIKI 组绩效表的差异：**
- J 列（标产2）和 K 列（爬坡目标）是商机组特有的
- N 列（绩效用作业量）公式更复杂，含爬坡逻辑
- S 列含义不同：商机组是"应审量"，WIKI 组是"准确率阈值"
- 不区分正式项目和临时项目

### 人员名单

| 列 | 字段名 | 说明 |
|:--:|:--|:--|
| A | 姓名 | |
| B | 工号 | WBxxxxxxxx |
| C | 状态 | 在职 / 离职 / 转出 / 汰换 |
| D | 转项/离职日期 | Excel 序列号 |

### 考勤表（与违规申诉组共用同一文档，每月新建 sheet）

矩阵格式：行=人员，列=日期。文档 nodeId 固定不变，每月新建一个 sheet，命名为 `2026年X月`。

**脚本自动按当前月份查找对应 sheet，无需人工维护 sheetId。**

| 列 | 说明 |
|:--|:--|
| A | 姓名 |
| D 起 | 日期列，表头格式 `月.日`（如 `6.25`） |

**单元格值含义（完整映射见 calculation-rules.md 商机组部分）：**
- `早4` → 全勤
- `请假`/`年假`/`病假`/`半天年假半天病假` → 全天假
- `请假上半天`/`请假下半天`/`年假半天` → 半天假
- `请假xh` → 小时假
- `休息`/`保护性事假`/`调休` → 不应出勤
- `调休半天`/`调休x小时` → 部分出勤（推送阈值调整）
- `离职`/`转项` → 永久移除
- `上班半天离职` → 不推送
- `休（加班）` → 节假日加班，看板正常计算
- 空值 → 触发报警
- 未知词 → 触发报警

## 违规申诉组（电子表格 Sheet）

与商机组结构高度相似，共用同一 Sheet MCP 和考勤文档，但数据文档不同。

### 绩效表（每月新建 sheet）

文档 nodeId 固定不变，命名规则同商机组：`2026年X月绩效`，脚本自动识别。

| 差异项 | 说明 |
|:--|:--|
| S 列含义 | 项目工时（非培训非答疑的纯生产/质检工时） |
| 姓名列 | 使用 LOOKUP 公式（INDEX+MATCH 从人员名单取），系统读取时按值处理 |
| 质检标产 | 与生产标产不同（如违规商品申诉处理：质检 200 / 生产 1300） |
| 答疑类型 | 按培训逻辑计算，但类型保持"答疑" |

### 人员名单

| 列 | 字段名 | 说明 |
|:--:|:--|:--|
| D | 姓名 | 注意：不是 A 列（与商机组不同） |
| E | 工号 | WBxxxxxxxx |
| F | 状态 | 在职 / 离职 / 转项（离职和转项不参与推送） |

### 考勤表

同商机组，共用同一文档，按月份 sheet 名自动识别（`2026年X月`）。

## 三种数据源对比

| | AI Table（大盘组） | 电子表格（WIKI 组） | 电子表格（商机/违规组） |
|:--|:--|:--|:--|
| 员工填报方式 | 表单（自动写入多维表） | 直接填绩效表 | 直接填绩效表 |
| 人员管理 | 多维表人员名单表 | 独立人员表文档（不同组织） | 同文档内不同 sheet |
| 项目配置 | 多维表项目表（组长维护） | `groups/wiki.json` | 自动从绩效表识别（无需配置） |
| 请假来源 | AI Table 日报录入表 | 量级登记表 | 独立考勤表 |
| 月度数据 | 永久累积，不用换表 | 需换新表，更新 nodeId/sheetId | 需换新表，更新 nodeId/sheetId |
| 字段扩展 | 加列即可，更新 json 映射 | 保持固定列顺序 | 保持固定列顺序 |
| 绩效公式 | 完成率（Σ量÷阈值） | 1500×量÷标产（Q列） | 含爬坡目标的三段公式（N列） |
