# 新组接入清单

接入新组前按以下清单逐项确认，确认完成后再开始配置。

---

## 一、基本信息

- [ ] 组名
- [ ] 负责人（组长）姓名
- [ ] 组员名单来源（哪个文档/表格，格式是什么）

---

## 二、数据源类型

**选择数据源类型：**

| 类型 | 适用场景 | 接入方式 |
|:--|:--|:--|
| **AI Table**（多维表） | 员工通过表单填报 | `setup_group.py` 自动建表 + MCP |
| **电子表格（Sheet）** | 已有现成 Excel/在线表格，由组长维护 | 手动配置 Sheet MCP + sheetId |

---

## 三、任务配置

- [ ] 有哪些正式项目？每个项目的名称、标产阈值、准确率阈值？
- [ ] 有哪些临时项目（如有）？标产、准确率阈值？
- [ ] 有没有培训类任务？是否纳入绩效计算？
- [ ] 有没有质检类任务？质检的考核标准是什么？

  > ⚠️ **质检类任务的计算口径需向用户单独确认**，不能套用生产的公式。
  > 当前各组处理方式：
  > - WIKI 组：质检准确率单独列，与生产分开显示
  > - 商机组：生产和质检准确率分列显示
  > - 违规申诉组：生产和质检准确率分列显示（示例人员12无准确率）

- [ ] 有没有临时任务（大盘组模式的豁免机制）？还是所有任务都有明确标产（WIKI/商机/违规模式）？
- [ ] 有没有答疑类任务？是否需要按培训逻辑计算但保持独立类型？（参考违规申诉组）

---

## 四、指标体系

- [ ] 个人达标用哪个公式？
  - 大盘组模式：完成率 = Σ(实际量÷阈值) ≥ 100%，临时任务触发豁免
  - WIKI 组模式：绩效用作业量之和 ≥ 1500（公式：1500×量÷标产）
  - 商机/违规模式：绩效用作业量之和 ≥ 1500（含爬坡目标的三段公式）
  - 其他：需单独确认

- [ ] 准确率达标阈值各项目是多少？

---

## 五、数据源连接

**AI Table 数据源：**
- [ ] 该组的 MCP URL（格式：`https://example.invalid/YOUR_MCP_ENDPOINT<id>?key=<key>`）

**电子表格数据源：**
- [ ] Sheet MCP URL（同上格式，mcpId=9704）
- [ ] 绩效表 nodeId + sheetId
- [ ] 人员表 nodeId + sheetId（可能在同文档或不同文档/不同组织）
- [ ] 请假数据来源：
  - 量级登记表 sheetId（WIKI 组模式：从量级列识别"请假"）
  - 独立考勤表 nodeId + sheetId（商机/违规模式：矩阵格式，按日期列匹配）
- [ ] 如用考勤表：考勤表的"休息"是否算请假？（商机组不算，违规申诉组算）

---

## 六、推送配置

- [ ] 正式群机器人 Webhook URL + 加签 Secret
- [ ] 推送内容：填报提醒？异常推送？人效日报？
- [ ] 各推送的时间点
- [ ] 推送格式有无特殊要求

---

## 七、看板

- [ ] 是否加入项目追踪看板？
- [ ] 在看板中显示的组名
- [ ] 运行看板数据更新的方式（手动触发 / 定时自动）

---

## 八、接入步骤

1. 确认以上所有参数
2. 创建 `groups/<组名>.json`，填入配置
3. 配置 MCP（调用 `setup()` 或在 skill 配置文件中添加）
4. 编写/复用推送脚本，用 `--test` 参数在测试群验证
5. 创建 CloudCLI 定时任务
6. 切换到正式群，完成交接
