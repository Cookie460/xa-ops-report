# Web 看板规格

## 总体设计

- 纯前端 HTML + Chart.js，无后端
- 读取 `groups/` 下所有 JSON 配置，自动生成多组视图
- 组长/主管浏览器打开即可查看，**不推送到群**

## 页面结构

### 首页（总览）

```
顶部：标题 + 周期选择器（日/周/月）+ 日期选择
内容：每组一个卡片模块
```

**组卡片格式：**
```
┌─ 大盘组 ──────────────── 负责人：示例人员1 ─┐
│                                           │
│  [大盘]          [SKU]                    │
│  CPD  吞吐  准确率    CPD  吞吐  准确率    │
│  428  1605  99.3%    410  1519  98.7%    │
│  ▲3%  ▲2%  ▼0.1%   ▼1%  ▼0.8% ▲0.3%   │
│                                           │
└───────────────────── 点击项目进入详情 → ──┘
```

- 每个启用项目显示 CPD / 吞吐 / 准确率 三个指标
- 数字下方标环比变化（▲绿=上升 ▼红=下降）
- 点击项目进入详情页

### 详情页（项目详情）

**顶部：汇总卡片**
- CPD / 吞吐 / 准确率 / 等效人数
- 每个卡片带环比（红绿箭头）

**中部：三张趋势图**

| 图表 | 目标线 | 说明 |
|:--|:--|:--|
| CPD 趋势 | 该项目达标阈值（如 400） | 红色虚线 |
| 吞吐趋势 | 1500 | 红色虚线 |
| 准确率趋势 | 95% | 红色虚线 |

图表样式：
- 渐变填充（半透明）
- 白色圆点 + 彩色边框
- 柔和曲线（tension 0.4）
- X 轴无网格线，Y 轴浅色网格
- chartjs-plugin-annotation 画目标线

**底部：员工准确率排名**
- 仅显示当周期有质检数据的员工
- 相同准确率并列排名（=5, =5, 7）
- 前三名金银铜标记
- 准确率旁带进度条（≥99% 绿 / ≥95% 黄 / <95% 红）
- 显示列：排名 / 姓名 / 准确率 / 质检量 / 不一致量

## 多组合并

新组加入看板：
1. `groups/` 下新增该组 JSON 配置
2. 看板 JS 遍历所有 group config，为每组渲染一个卡片模块
3. 不同组之间独立，各读各的多维表数据

正式版数据流：
```
页面加载 → 读 groups/*.json → 对每组：
  配置 MCP → 读项目表 → 读日报录入 → 读人员名单
  → 前端计算 CPD/吞吐/准确率
  → 渲染卡片 + 趋势图 + 排名
```

## 周期选择

| 周期 | 趋势图点数 | 标签格式 |
|:--|:--|:--|
| 日 | 10 天 | 06-22 |
| 周 | 6 周 | 06-16~06-22 |
| 月 | 4 月 | 2026-06 |

切换周期时首页和详情页联动刷新。
