# 指标计算口径（最新版）

## 一、个人达标 — 群推送用（所有组通用判断逻辑）

### 大盘组（AI Table 数据源）

**完成率**
```
完成率 = Σ(各正式项目实际量 ÷ 该项目达标阈值)
请假等比放大：
  半天 → 完成率 × 2（= ×8/4）
  1小时 → 完成率 × 8/7
  2小时 → 完成率 × 8/6
  3小时 → 完成率 × 8/5
全天请假 → 不参与，显示"休 🏖️"
```

**达标判断**
```
完成率 ≥ 100% → 达标 ✅
完成率 < 100% + (临时任务工时 > 0 或 培训工时 > 0) + 已豁免 → 达标 ✅
否则 → 未达标
```

**连续不达标通报**
```
若某人连续三个工作日量级均未达标 → "⚠️ xxx同学连续三天量级未达标，请组长关注"
若某人连续三个工作日准确率均未达标 → "⚠️ xxx同学连续三天准确率未达标，请组长关注"
两者均连续三天 → "⚠️ xxx同学连续三天量级及准确率均未达标，请组长关注"
请假天不计入连续不达标判断
```

**看板总工时**
```
总工时 = 各项目工时 + 临时任务工时 + 培训工时
请假：全天+1，半天+0.5，x小时+x/8
```

**个人准确率（按项目）**
```
准确率 = (1 - 该项目不一致量 ÷ 该项目被质检量) × 100%
被质检量 = 0 → 显示 "—"
< 95% → 加 ❗
```

**全员达标判断**
```
作业量全部达标 AND 所有人准确率 ≥ 95% → "太棒啦，我们真厉害！全员达标 🎉🎉🎉"
否则 → "还有小伙伴没达标哦，加油呀 💪"（不点名）
```

### WIKI 组（电子表格数据源）

**绩效用作业量（直接读绩效表 Q 列）**
```
生产/质检（无工时）: 1500 × 作业量 ÷ 标产阈值
培训（有工时）: 1500 × 作业工时 ÷ 8
四舍五入取整
```

**达标判断**
```
当天所有记录绩效用作业量之和 ≥ 1500 → 达标 ✅
< 1500 → 未达标
绩效表无记录 且 量级登记标注请假 → 休 🏖️（不影响全员达标）
绩效表无记录 且 未请假 → 未填报
```

**个人准确率（生产和质检分开列）**
```
生产准确率 = (1 - 生产不一致量 ÷ 生产被抽检量) × 100%
质检准确率 = (1 - 质检不一致量 ÷ 质检被抽检量) × 100%
无被抽检数据 → 不显示该列（表头动态）
```

**请假来源：** 量级登记表，量级列填"请假"即为请假

### 商机组（电子表格数据源）

**绩效用作业量（绩效表 N 列公式，含爬坡目标和标产2）**
```
=ROUND(IF(K=0, IF(J=0, 1500*L/I, 1500*L/J), 1500*K/8), 0)

I = 标产（col 8），J = 标产2（col 9），K = 爬坡目标/作业工时（col 10），L = 作业量（col 11）
含义：
  - 有爬坡目标或培训工时(K>0)：1500*K/8
  - 无爬坡但有标产2(J>0)：1500*L/J（用标产2作为分母）
  - 都没有：1500*L/I（用原始标产）
四舍五入取整，脚本直接读 N 列结果
```

**达标判断**
```
当天所有记录绩效用作业量之和 ≥ 1500 → 达标 ✅
< 1500 → 未达标
绩效表无记录 且 考勤表标注请假/年假/病假 → 休 🏖️
绩效表无记录 且 考勤表半天假 → 半天假
绩效表无记录 且 无请假 → 未填报
```

**个人准确率（生产和质检分列）**
```
生产：有被抽检量+不一致量 → 显示生产准确率
质检（情况1）：有被抽检量+有不一致量（含0）→ 显示质检准确率
质检（情况2）：有被抽检量+无不一致量 → 不显示（该数值代表检查了多少条，不是准确率）
```

**请假来源：** 独立考勤表（商机组与违规申诉组共用同一 sheet）

| 考勤表值 | 推送影响 | 看板影响 |
|:--|:--|:--|
| **常见** | | |
| `早4` | 全勤 | 正常计算 |
| `请假`/`年假`/`病假`/`半天年假半天病假` | 全天假（休🏖️） | 请假+1 |
| `请假上半天`/`请假下半天`/`年假半天` | 半天假 | 请假+0.5 |
| `请假xh` | 小时假 | 请假+x/8 |
| `离职`/`转项` | 不推送 | 不计入 |
| `休息`/`保护性事假`/`调休` | 不应出勤，不推送 | 请假+0 |
| `调休半天` | 推送，阈值=750 | 请假+0 |
| `调休x小时` | 推送，阈值=1500×(8-x)/8 | 请假+0 |
| **罕见** | | |
| `上班半天离职` | 不推送 | 请假+0 |
| `休（加班）` | 节假日不推送 | 正常计算 |
| **异常** | | |
| 全列空值 | 失败+报警 | 失败 |
| 未知词 | 失败+报警 | 失败 |

**特殊规则：**
- 不区分正式项目和临时项目，所有任务一视同仁
- 应审量在 S 列（col 18），看板吞吐直接用应审量之和作为应产出
- 看板等效人数 = Σ(每人应审量 / 标产)，不推算工时
- 看板不读考勤表（推送仍读）

### 违规申诉组（电子表格数据源）

**绩效用作业量（绩效表 N 列公式，同商机组）**
```
=ROUND(IF(K=0, IF(J=0, 1500*L/I, 1500*L/J), 1500*K/8), 0)
同商机组，四舍五入取整，脚本直接读 N 列结果
```

**达标判断**
```
同商机组逻辑，≥ 1500 达标
但请假判断不同（见下方）
```

**个人准确率（生产和质检分列，同商机组规则）**
```
生产：有被抽检量+不一致量 → 显示
质检（情况1）：有被抽检量+有不一致量 → 显示
质检（情况2）：有被抽检量+无不一致量 → 不显示
示例人员12（仅质检+答疑）：推送只推量级，不显示准确率
```

**请假来源：** 同商机组考勤表（同一个 sheet），映射规则完全相同

> 注：脚本是否执行由 `is_workday()` 独立判断，与考勤表无关。违规组有非工作日排班，看板会记录，推送不管。

**特殊规则：**
- 质检标产和生产标产从绩效表 I/J 列读取，不写死
- 答疑类型：按培训逻辑计算绩效（1500×工时÷8），但类型列保持"答疑"
- 总工时 = S 列（项目工时，生产/质检）+ K 列（作业工时，培训/答疑）
- 示例人员12（exclude_employees）：看板完全排除，推送只推量级
- 姓名列使用 LOOKUP 公式，系统读取时按值处理

## 二、任务维度 — Web 看板

> **核心原则：CPD 和吞吐只围绕"生产"维度。质检/培训/答疑的工时属于非生产工时，不贡献产量。**

### 等效人数（CPD 分母）

```
某项目等效人数 = Σ 每个做了该项目生产的人(该项目生产工时 ÷ 该人总工时)

分子：只算生产工时，不含质检工时
分母：该人当天所有工时（生产 + 质检 + 培训 + 答疑）
只做了质检没做生产的人：不参与等效人数计算

各组差异：
  大盘组：AI Table 字段直接读
  WIKI组：从量级登记表推算
          单项目：生产工时 = 8 - 非任务时长
          多项目：主项目工时 = 8 - 非任务时长 - Σ副项目工时（从备注提取）
          副项目工时从"具体内容"列提取（如"款采集5h"）
  商机组：等效人数 = Σ(每人应审量 / 标产)，不推算工时
  违规组：总工时 = S列(生产/质检) + K列(培训/答疑)
```

### CPD

```
某项目 CPD = 该项目总生产量 ÷ 该项目等效人数
总生产量 = 只算类型="生产"的作业量，质检的量不计入
无工时数据（历史记录）→ 显示 "—"
```

### 应产出量

```
应产出量 = 标产 × 总人头数 - 非生产工时 × (标产 ÷ 8)

总人头数 = 今天做了该项目生产的人数 + 请假人数
  - 只做了质检没做生产的人：不算入总人头
  - 既生产又质检的人：算入总人头，质检工时算非生产工时
  - 请假人数只计入当天生产工时最多的主项目

非生产工时 = 对做了该项目生产的每个人：（该人总工时 - 该项目生产工时）
  - 包含：质检时间、其他项目时间、培训时间、答疑时间
  - 不包含：没做该项目生产的人的任何时间
无工时数据 → 不计算（吞吐显示 "—"）
```

### 吞吐

```
吞吐 = 项目总生产量 ÷ 应产出量 × 1500

（商机组）吞吐 = 项目总生产量 ÷ 应审量之和 × 1500

= 1500 → 刚好达标；> 1500 → 超额；< 1500 → 未达标
达标线：1500（趋势图红色虚线）
```

### 准确率（看板汇总）

```
项目准确率 = (1 - 生产不一致量之和 ÷ 生产被质检量之和) × 100%
看板只用生产记录的抽检数据，质检记录不参与看板准确率
无质检数据的人不计入
```

### 周/月度聚合

```
只聚合有工时的天（避免历史无工时记录污染分母）
请假也只统计有工时天数中的请假
某项目只做了几天 → 按实际有数据的天聚合，不影响其他项目
```

### 环比

```
日 → 跟前一天比
周 → 跟上一周比
月 → 跟上一月比
▲ 绿色 = 上升；▼ 红色 = 下降
```

## 三、质检类任务

**看板：** 质检不纳入 CPD、吞吐、准确率计算（看板只算生产）。质检工时属于"非生产工时"。

**推送准确率：**
- 生产准确率：有值即推送
- 质检准确率（情况1）：被抽检量+不一致量都有值 → 推送（质检后被验收方抽检）
- 质检准确率（情况2）：被抽检量有值+不一致量为空 → 不推送（代表检查了多少条）

各组推送准确率列：
- **WIKI 组**：生产和质检分列显示
- **商机组**：生产和质检分列显示
- **违规申诉组**：生产和质检分列显示（示例人员12无准确率）

## 四、培训与答疑

培训只影响量级（绩效用作业量），**不纳入准确率、CPD、吞吐计算**。
培训工时属于"非生产工时"，会影响生产的等效人数。

各组差异：
- **WIKI 组**：培训类型为"培训-业务需求"
- **商机组**：培训类型为"培训-业务需求"
- **违规申诉组**：答疑按培训逻辑计算绩效（1500×工时÷8），但类型保持"答疑"不改为培训，在日报中也显示为答疑
