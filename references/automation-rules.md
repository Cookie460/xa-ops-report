# 自动化推送规则

## 总体原则

- 所有推送仅在中国法定工作日执行，含调休补班日
- 节假日判断：timor.tech API（type 0/3 = 工作日）
- API 不可用时降级为周一至周五判断

---

## 大盘组（3条推送）

### 1. 填报提醒

| 项目 | 说明 |
|:--|:--|
| 脚本 | `push_dapan_reminder.py dapan` |
| 时间 | 17:40 |
| Cron | `40 17 * * 1-5` |
| 内容 | actionCard，@所有人，附"去填写"按钮 |
| 数据 | 无（只发提醒） |

### 2. 异常推送

| 项目 | 说明 |
|:--|:--|
| 脚本 | `push_dapan_anomaly.py dapan` |
| 时间 | 18:15（延后15分钟等多维表 API 同步） |
| Cron | `15 18 * * 1-5` |
| 内容 | 未填报名单 + 需豁免确认名单 |

**异常检测逻辑：**
1. 在职员工 − 今日已填报 = 未填报
2. 完成率 < 100% 且 临时任务量 > 0 且 未标豁免 → 推给组长确认
3. 全天请假、转出、离职 → 不参与判断

### 3. 人效日报

| 项目 | 说明 |
|:--|:--|
| 脚本 | `push_dapan_daily.py dapan` |
| 时间 | 10:30 次日 |
| Cron | `30 10 * * *`（每天，脚本内判断工作日） |
| 内容 | 每人达标情况 + 各项目准确率（表头动态） |

**日期顺延：** 从昨天往前找最近工作日，最多回溯10天（覆盖春节等长假）

**推送格式（markdown 表格）：**

| 姓名 | 实际作业量 | 大盘准确率 |
|:---:|:---:|:---:|
| 张三 | 达标 ✅ | 99.5% |
| 李四 | 休 🏖️ | — |

- 无工时数据（历史记录）→ 准确率照常，CPD/吞吐显示"—"
- 准确率 < 95% → 加 ❗
- 全员量级达标 + 准确率全部 ≥ 95% → "太棒啦，我们真厉害！全员达标 🎉"
- 否则 → "还有小伙伴没达标哦，加油呀 💪"（不点名）
- 若有人连续三个工作日量级或准确率不达标（请假天不计），日报末尾追加：`⚠️ xxx同学连续三天量级未达标，请组长关注`（量级和准确率分别判断，两者都连续不达标则合并提示）

## WIKI 组（1条推送）

### 人效日报

| 项目 | 说明 |
|:--|:--|
| 脚本 | `push_wiki_daily.py` |
| 时间 | 11:30 次日 |
| Cron | `30 11 * * *`（每天，脚本内判断工作日） |
| 内容 | 每人量级达标 + 各项目生产/质检准确率（表头动态） |

**数据来源：** 绩效表（量级 + 准确率）+ 量级登记（请假识别）

**量级达标：** 当天所有记录绩效用作业量之和 ≥ 1500（直接读绩效表 Q 列）

**请假识别：** 读量级登记表，量级列填"请假"→ 显示"休 🏖️"，不影响全员达标

**准确率列：** 生产和质检分开列，当天有质检数据才显示对应列，无数据不显示

**推送格式（markdown 表格）：**

| 姓名 | 量级 | repo机审(生产)准确率 | repo机审(质检)准确率 |
|:---:|:---:|:---:|:---:|
| 张三 | 达标 ✅ | 100.0% | — |
| 李四 | 休 🏖️ | — | — |

## 商机组（1条推送）

### 人效日报

| 项目 | 说明 |
|:--|:--|
| 脚本 | `push_shangji_daily.py` |
| 时间 | 11:00 次日 |
| Cron | `0 11 * * *`（每天，脚本内判断工作日） |
| 内容 | 每人量级达标 + 各项目准确率（生产/质检分列） |

**数据来源：** 绩效表（量级 + 准确率）+ 考勤表（请假识别）

**请假识别：** 考勤表映射规则见 calculation-rules.md 商机组部分

**准确率列：** 生产和质检分列显示（质检仅在有不一致量时显示）

**推送格式（markdown 表格）：**

| 姓名 | 量级 | 商机准确率 |
|:---:|:---:|:---:|
| 张三 | 达标 ✅ | 99.5% |
| 李四 | 休 🏖️ | — |
| 王五 | 半天假 | — |
